# LX File Exploder

A macOS app for working with MVR and Depence show files.

## Install or update

Open Terminal and run:

```bash
curl -fsSL https://raw.githubusercontent.com/oliverh57/MVR-Exploder/main/install.sh | bash
```

It downloads the latest version into Applications and opens it. Run the same command to update.

Requires macOS 14.4 or later, on Apple silicon or Intel.

## Licence

The app needs a licence file (`.lxlicence`) to run. When it opens, drag the file you were given onto the window, or click **Choose Licence File…**.
